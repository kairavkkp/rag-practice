What I learned

  • Measure chunks in tokens, not words. IDs and code turned one 498-word chunk into 4,363 tokens.
  • Meaning search misses exact IDs; keyword search misses rephrasing. Each failed different questions.
  • Merging the two made results worse at first. The reranker is what fixed it.
  • No score threshold could tell answerable from unanswerable. "I don't know" has to come from the prompt.

Coming next

  • Date awareness: prefer the newest note when facts change
  • Query rewriting and HyDE for loosely worded questions
  • Grading the answers, not just the retrieval
  • Re-running everything on a different, public dataset
